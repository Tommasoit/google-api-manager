Privacy notice

Effective date: 2 November 2026 · Operator: Tao Lin (林涛)

This notice covers the private desktop utility and its public documentation pages. The utility is operated by its owner; access to client accounts depends on the permissions granted by those account owners.

1. Data accessed and its purpose

After the user grants Google OAuth access, the utility can retrieve authorized advertising account identifiers and names, account relationships, reporting data, Analytics properties and web streams, aggregated website statistics, and Merchant Center account, product and product-status data. Access is limited by the signed-in user's Google permissions and by the API methods used.

The data is used to confirm account access, inspect account and website performance, diagnose integration or product issues, and prepare reports requested by the owner. The present workflow does not intentionally request individual shoppers' names, email addresses, passwords, payment-card details or postal addresses.

The permissions are adwords, analytics.readonly and content. The Ads and Merchant scopes are broader than read-only; the current workflow restricts normal operations to reads. Any approved configuration change is treated separately from reporting.

2. Local storage and credential security

OAuth access and refresh tokens are encrypted on the owner's Windows computer using user-level Windows DPAPI. The local credential directory is restricted to the Windows user and SYSTEM. The downloaded OAuth client configuration is kept locally.

Credentials are sent only to Google's official authentication or API endpoints as required for authentication. They are excluded from public website files, repositories, normal report output and AI-assistant messages. Authorization callback codes are not written to HTTP access logs.

Reports and diagnostic files are saved locally. This documentation website has no database for Google account data, no OAuth callback endpoint and no credential upload form.

3. Processing by service providers

Google: Google authenticates the user, presents the consent screen and provides the authorized API responses under Google's applicable terms and privacy policies.

OpenAI / Codex: The owner uses Codex to help operate the local utility and analyze selected results. Relevant account metadata, report excerpts and diagnostic results may be transmitted to OpenAI as part of the owner's requested assistance. OpenAI's processing is subject to the owner's service terms and account data controls. OAuth credentials must not be included in that material. The utility itself does not train AI models; external processing must comply with applicable Google API data-use restrictions.

GitHub Pages: GitHub hosts these public, static documentation files. GitHub processes ordinary website request information, including IP addresses for security purposes, as described in its privacy statement. The site contains no advertising pixels, analytics scripts, embedded remote fonts or optional tracking cookies.

Google API data is not sold or rented by the operator, and is not used by this utility to build unrelated advertising profiles. Account data is not made public through these documentation pages.

4. Retention and deletion

Local credentials and reports remain on the owner's computer until the owner deletes the relevant files. Revoking Google access stops further use of that authorization but does not automatically erase local credentials or reports. The owner must delete any local exports that are no longer needed and can request handling of provider-held conversation data through the relevant provider's controls.

To withdraw Google access, visit Google Account connections and remove access for Codex Google Ads Manager. This prevents further use of the revoked authorization. The owner can also delete the local encrypted credentials and local report files.

5. Google API data-use commitments

The use and transfer of information received from Google APIs must comply with the Google API Services User Data Policy, including its Limited Use requirements where applicable. The utility uses Google data for the owner-authorized account management and reporting functions described here.

6. Contact and changes

This notice will be updated when the utility's data handling changes materially. The effective date above identifies the current published version.
